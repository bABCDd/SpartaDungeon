스파르타 던전 탐험 만들기 제출 과제입니다. _김상균

이번 프로젝트에서는 3D를 활용해 플레이어를 만들고 플레이어와 상호작용하는 다양한 오브젝트를 만들어보았습니다.

먼저 인풋 시스템을 활용하여 Move, Look, Jump, Interaction을 구현하였습니다. 또한 Capsule Collider와 Rigidbody를 활용하여 물리작용을 할 수 있도록 만들었습니다.

그렇게 만들어진 캐릭터가 움직일 수 있는 Ground를 추가하고 플레이어와 마찬가지로 Collider를 추가하여 플레이어가 그라운드 위에서 움직일 수 있도록 구현하였습니다.

이후엔 체력, 배고픔, 스테미너 수치를 확인할 수 있는 UI를 만들고 PlayerComdition 스크립트에서 각 수치가 조절될 수 있는 메서드를 작성하였습니다.

2D Sprite 패키지 매니저를 활용해 이미지 타입을 Filled - Horizontal - Left로 설정하여 이미지가 코드에 따라 실시간으로 변화하는 모습을 구현할 수 있었습니다.

아이템 오브젝트의 경우 ScriptableObject로 정보를 관리하여 아이템의 이름, 설명, 속성 정보를 관리하였고 플레이어로부터 Ray를 발사하여 특정 거리에서 해당 오브젝트를 보았을 때 오브젝트에 저장된 정보가 ui로 표시되도록 하였습니다.

플레이어 정면에 존재하는 스퀘어 모양의 아이템도 정보를 확인할 수 있으며 플레이어가 해당 아이템과 닿았을 경우 특정 시간에 걸쳐 배고픔을 점점 회복하는 기능을 코루틴을 활용하여 구현하였습니다.

아이템 뒤에 존재하는 Plane 오브젝트의 경우 점프대 기능을 하며 순간적인 힘을 가할 수 있도록 AddForce메서드에 ForceMode.Impurse를 활용하여 점프대를 구현하였습니다.
